# BGO Executive Dashboard — Backend

This is the unified FastAPI backend, merged from the original Report Factory and the existing
Executive Dashboard. See the root `CLAUDE.md` for full project documentation.

## Running the Backend

```bash
cd d:\dashboard\backend
pip install -r requirements.txt
python seed_catalog.py          # seed kpi_catalog (run once or after catalog changes)
uvicorn main:app --reload       # http://localhost:8000
# Docs: http://localhost:8000/docs
```

## Two API Flows

### Direct (Upload → Dashboard)
1. `POST /upload` — upload file with `file_type`; triggers parse → profile → schema_inference
2. `GET /upload/{id}/profile` — poll until status=profiled
3. `GET /upload/{id}/mapping` — retrieve AI-inferred column mapping
4. `POST /upload/{id}/mapping/confirm` — confirm mapping; get available/blocked KPIs
5. `POST /api/sessions/{id}/analyze` — pass selected KPI IDs; triggers bronze→silver→gold
6. `GET /api/sessions/{id}/status` — poll until status=complete
7. `GET /api/sessions/{id}/dashboard` — fetch computed KPI results
8. `GET /api/sessions/{id}/export/excel` or `/export/pptx` — download reports

### AI Interview Path (for reusable recipes)
1. `POST /upload` — same upload step
2. `POST /interview` — 5-step chat (date_col → KPIs → dimensions → granularity → filters)
3. `POST /interview/recipe` — create RecipeConfig from interview result
4. `POST /interview/recipe/{id}/approve` — freeze recipe; triggers gold computation
5. → same dashboard + export

## Adding New KPIs

1. Add entries to `backend/kpi_registry/definitions/<domain>.yaml`
2. Run from project root: `python migrate_yaml_kpis.py`
3. Run: `cd backend && python seed_catalog.py`
4. No code changes required.

## Key Environment Variables

| Variable | Default | Purpose |
|----------|---------|---------|
| `DATABASE_URL` | `sqlite:///./dev.db` | Database connection |
| `OPENAI_API_KEY` | (empty) | Required for schema inference + interview |
| `S3_BUCKET` | `local` | Storage bucket (empty = local filesystem) |
| `AWS_ACCESS_KEY_ID` | (empty) | Leave empty for local filesystem fallback |
| `APP_ENV` | `development` | Set to `production` to hide /docs |
